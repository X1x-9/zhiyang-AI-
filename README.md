# 智养 AI

懂你的饮食、训练与日常节奏的健康生活教练。记录一餐、安排一日、复盘一周，让健康计划跟得上真实生活。

- Next.js 16 · React 19 · TypeScript
- Tailwind CSS 4
- Prisma · AI SDK

## 本地运行

1. 安装依赖：`npm install`（仓库不包含 `node_modules`）。
2. 复制 `.env.example` 为 `.env.local`，填入数据库与模型服务配置；不要提交真实密钥。
3. 启动开发服务：`npm run dev`，默认 http://localhost:3000。
