## 本地运行

1. 安装依赖：`npm install`（仓库不包含 `node_modules`）。
2. 复制 `.env.example` 为 `.env.local`，填入数据库与模型服务配置；不要提交真实密钥。
3. 准备数据库：按 `prisma/schema.prisma` 建库，或运行 `npm run db:setup` / `npx prisma db push`。
4. 启动开发服务：`npm run dev`，默认 http://localhost:3000。
